# Safe Root Things

A collection of small, reversible tweaks for rooted headsets - LED effects, dock/navigator behavior, panel tricks, and a few utilities.

> [!NOTE]
> Everything here requires a rooted headset with root shell access. See the [Root Guide](/meta/RootGuide.md) if you haven't rooted yet.

## Categories

- **LED** - [Rainbow LED](meta/roottweaks/led/RainbowLed.md), [Power Indicator LED](meta/roottweaks/led/PowerIndicatorLed.md)
- **Navigator / Dock** - [Navigator Background Fog](meta/roottweaks/navigatordock/NavigatorFog.md), [Rebootless UI Switching](meta/roottweaks/navigatordock/RebootlessUiSwitching.md)
- **Panel Behavior** - [Fixed Panel Scaling](meta/roottweaks/panelbehavior/FixedPanelScaling.md), [Infinite Floating Panels](meta/roottweaks/panelbehavior/InfiniteFloatingPanels.md), [Floating Bar](meta/roottweaks/panelbehavior/FloatingBar.md), [Hulk UI](meta/roottweaks/panelbehavior/HulkUi.md)
- **VR Behavior** - [Teleport Anywhere](meta/roottweaks/vrbehavior/TeleportAnywhere.md), [No Controller Requirement](meta/roottweaks/vrbehavior/NoControllerRequirement.md), [Void Transition](meta/roottweaks/vrbehavior/VoidTransition.md), [Report Menu to Dock Library](meta/roottweaks/vrbehavior/ReportToLibrary.md)
- **Utilities / Info** - [Dogfood Hub](meta/roottweaks/utilities/DogfoodHub.md), [Controller Info](meta/roottweaks/utilities/ControllerInfo.md), [Rainbow Draw Frame](meta/roottweaks/utilities/RainbowDrawFrame.md)

Also worth knowing about: [Dock Editor](https://github.com/Lumince/DockEditor) - a full dock customization app, installed as an APK rather than run from a shell.
