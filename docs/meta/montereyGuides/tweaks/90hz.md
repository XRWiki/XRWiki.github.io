#  90Hz Display Mod

While the quest's displays can operate at 90hz, they are capped at 72hz by the operating system, this can be resolved by patching the boot image to unrestrict the refresh rate.


## Requirements

* Unlocked bootloader
* [Root](meta/montereyGuides/magisk.md) (via either method)
* V37 or V50 (see [Changing your Firmware](meta/montereyGuides/changefirm.md))
* The Patched boot.img for your firmware, ([V37](https://cdn.discordapp.com/attachments/1492978347079368928/1526786457396576266/v37modboot.img?ex=6a8fa931&is=6a8e57b1&hm=5a5f2c5d236eb970c4e88e0cff3361acdb6bfcb300e9de5c1b71389cf197195b&), V50)

If you have already rooted with Magisk, you must patch the modified boot.img with Magisk first.

## Apply Temporarily 
Boot your device into fastboot, while it is in fastboot enter the following..

```shell
fastboot boot [patched boot img]
```
Replace "[patched boot img]" with the img file you downloaded for your firmware

Once the quest has booted, enter into `adb root` and run these commands

```shell
adb shell setprop debug.oculus.refreshRate 90
adb shell settings put system peak_refresh_rate 90
adb shell settings put system min_refresh_rate 90
adb shell settings put global peak_refresh_rate 90
adb shell settings put global min_refresh_rate 90
adb shell setprop debug.sf.refresh_rate 90
```
