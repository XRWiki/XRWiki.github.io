#  90Hz Display Mod

While the quest's displays can operate at 90hz, they are capped at 72hz by the operating system, this can be resolved by patching the boot image to unrestrict the refresh rate.


## Requirements

* Unlocked bootloader
* V50 (see [Changing your Firmware](meta/montereyGuides/changefirm.md))
* The patch files available [here](https://mega.nz/file/uQkwDIxK#A4vvjF5ZYrnnruQNtX3uwVleccWw86vFKlS-WGH1HHY)

# Flashing the patched image
Make sure you have extracted the zip file containing the boot image and magisk module

First is to figure out your boot slot, boot into fastboot with `adb reboot bootloader`, then run
```shell
fastboot getvar current-slot
```
Note down your current slot (a or b)

With the current slot, run the following command

```shell
fastboot flash boot_[current slot] s4_120_hfp250_phy.img

fastboot reboot
```

Once you are back into Horizon OS, open the magisk app from unknown sources and accept the download prompt.

Once installation has finished open magisk and make sure it does not need any extra configuration

You can now return to a terminal on your pc and run the following

```shell
adb push path/to/your/vd90hz-v3.zip /data/local/tmp
adb shell 
su 
magisk --install-module /data/local/tmp/vd90hz-v3.zip
reboot
```

> [!NOTE]
> You may need to enter sleep/wake once every boot for the patch to take effect


Put the headset on and let something render for a few seconds, then run:
```shell
adb shell "logcat -d | grep -oE 'FPS=[0-9]+/[0-9]+' | tail"
```

You should see lines like so:
`FPS=90/90`
