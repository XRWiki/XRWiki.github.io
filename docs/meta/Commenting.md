# Comments

Every page has a comment box at the bottom. It runs on your GitHub account, and
the threads live in this wiki's [GitHub Discussions](https://github.com/XRWiki/XRWiki.github.io/discussions)
— so a comment is as searchable and as permanent as the page it sits under.

Press **Sign in with GitHub** the first time. Nothing else is needed, and no
permission has to be granted to you by anyone.

## What comments are for

The things that do not belong in the guide itself:

- A build number that has moved on since the page was written.
- A step that did not work on your headset, and what you did instead.
- A warning worth adding — something that bricked a device, or nearly did.
- Asking whether a guide still applies to newer hardware.

Say which headset and which build you are on. "Doesn't work" is impossible to
act on; "fails on eureka, build 1026601864, at the `adb push` step" is a bug
report someone can fix.

## Reactions

The emoji row at the top of each thread is worth using. A guide with twenty
👍 and no comments is a guide that works, which is information the page cannot
carry on its own.

## Who looks after each page

The **Maintainers** line at the top of every page names whoever is responsible
for it, and **History** next to it is that page's full list of changes. If a
comment goes unanswered, the maintainer is who to mention.

## Getting a page changed

Comments do not edit the page — they are the conversation, and the page is the
answer. When something in a guide is actually wrong, the fix goes through
GitHub:

- **Small and obvious?** Leave a comment. A maintainer will fold it in.
- **You know exactly what it should say?** Open a pull request on
  [the repository](https://github.com/XRWiki/XRWiki.github.io). Every page is a
  markdown file under `docs/`, and GitHub's own editor will fork the wiki and
  open the pull request for you.

## Moderation

Comments are moderated by the wiki's owners through GitHub Discussions. Anything
dangerous, off-topic or hostile gets hidden. Posting a method you have not
tested yourself, on a page about modifying expensive hardware, counts as
dangerous — say so plainly if you are guessing.
